# Separate 16-feature MLP investigation

Team 9 also supplied a completed 16-feature MLP project. This folder archives
its training/evaluation source, feature configuration, metrics, cross-validation
results and fitted classifier. It used a 75 m candidate radius, up to eight
candidate arcs and a different weak-label alignment, so its scores are not
included in the common four-feature, 50 m five-model table. Raw input and
prepared trip files remain in the separately supplied MLP project folder.
